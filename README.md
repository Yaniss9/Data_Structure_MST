# Road Reparation - Minimum Spanning Tree

## Problem

This project solves the "Road Reparation" problem from the CSES Problem Set.

Problem link:
https://cses.fi/problemset/task/1675

## Description

Given several cities and roads with repair costs,
the goal is to connect all cities with the minimum total cost.

If it is impossible to connect all cities,
the program outputs:

IMPOSSIBLE

## Algorithm Used

* Kruskal's Algorithm
* Union-Find (Disjoint Set Union)

## Time Complexity

O(m log m)

## Language

C++
